# 11. Search

> For: **Both** — Content Editors manage synonyms from the backoffice; Developers integrate search into the frontend.

uTPro provides a built-in full-text search system powered by **Examine** (Lucene) with optional enhancements via the **SearchPlus** package.

---

## 11.1 Overview

| Layer | Component | Description |
|-------|-----------|-------------|
| **Core** | `ISearchExtension` | Full-text search service — inject in controllers or views |
| **Enhancement** | `uTPro.Feature.SearchPlus` | Diacritics-insensitive indexing + synonym expansion |
| **Backoffice** | Search Plus Workspace | Manage synonyms from Settings → uTPro Feature → Search Plus |

---

## 11.2 Core Search (`ISearchExtension`)

The search extension is registered automatically via `SearchExtensionComposer`. Inject `ISearchExtension` anywhere you need site search.

### Parameters

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `query` | string | — | Search term (user input) |
| `scope` | string | `"selectedSource"` | `"allSite"`, `"currentFolder"`, or `"selectedSource"` |
| `scopeNodeId` | int? | null | Restrict results to descendants of this node |
| `page` | int | 1 | Current page (1-based) |
| `pageSize` | int | 10 | Results per page |
| `fields` | string[]? | null | Specific fields to search (null = all) |
| `orderBy` | string[]? | null | Sort fields, e.g. `"updateDate Long desc"` |

### Usage in a Controller

```csharp
using uTPro.Extension.Search;

public class SearchController : Controller
{
    private readonly ISearchExtension _search;

    public SearchController(ISearchExtension search)
    {
        _search = search;
    }

    [HttpGet("/search")]
    public IActionResult Search([FromQuery] string q, int page = 1)
    {
        var results = _search.Search(q, scope: "allSite", page: page, pageSize: 10);

        return View(results);
    }
}
```

### Usage in a Razor View

```cshtml
@inject ISearchExtension Search

@{
    var q = Context.Request.Query["q"].FirstOrDefault() ?? "";
    var results = Search.Search(q, scope: "allSite", page: 1, pageSize: 20);
}

<h2>@results.TotalResults results for "@q"</h2>

@foreach (var item in results.Items)
{
    <div>
        <a href="@item.Content.Url()">@item.Content.Name</a>
        <span>Score: @item.Score</span>
    </div>
}
```

### Scope Modes

- **`allSite`** — search all published content
- **`currentFolder`** — restrict to descendants of the current Home node (auto-detected)
- **`selectedSource`** — restrict to descendants of `scopeNodeId`

## 11.3 SearchPlus — Diacritics-Insensitive Search

When `uTPro.Feature.SearchPlus` is installed, the Examine ExternalIndex is enhanced with an **ASCII Folding** analyzer. This allows users to search without accents and still find accented content.

**Example:** User types "tham khao" → matches content containing "Tham khảo"

Supports Vietnamese, French, Spanish, German, Portuguese, Turkish, Polish, Czech and more.

> ⚠️ After first install, **rebuild the ExternalIndex** once (Examine Dashboard → Rebuild).

📖 **Full documentation:** [uTPro.Feature.SearchPlus](/uTPro.Feature.SearchPlus/) · [How It Works](/uTPro.Feature.SearchPlus/how-it-works/) · [Diacritics](/uTPro.Feature.SearchPlus/diacritics/)

## 11.4 SearchPlus — Synonym Expansion

Synonyms allow a search for "laptop" to also match "máy tính", "computer", "notebook" — all terms in the same group.

- **Immediate effect** — add/edit/delete synonyms takes effect on next search, no index rebuild
- **Diacritics-insensitive lookup** — searching "cong ty" matches the "công ty" synonym group
- **Automatic integration** — when SearchPlus is installed, `ISearchExtension` automatically expands queries
- **25 pre-seeded groups** on first install

📖 **Full documentation:** [Synonym Management](/uTPro.Feature.SearchPlus/synonym-management/) · [Integration](/uTPro.Feature.SearchPlus/integration/)

## 11.6 Frontend Search Page

uTPro provides `ISearchExtension` as a service — you build the search page to match your site's design. A typical implementation:

1. **Search form** — input field + submit button on your layout or search page
2. **Search controller/view** — inject `ISearchExtension`, call `Search()`, render results
3. **Pagination** — use `TotalResults`, `TotalPages`, `Page` from `SearchResultSet`

### Example: Complete Search Page

```cshtml
@using uTPro.Extension.Search
@inject ISearchExtension Search
@{
    Layout = "_Layout";
    var q = Context.Request.Query["q"].FirstOrDefault() ?? "";
    var page = int.TryParse(Context.Request.Query["page"], out var p) ? p : 1;
    var results = string.IsNullOrWhiteSpace(q)
        ? new SearchResultSet()
        : Search.Search(q, scope: "allSite", page: page, pageSize: 10);
}

<h1>Search</h1>

<form method="get">
    <input type="text" name="q" value="@q" placeholder="Search..." />
    <button type="submit">Search</button>
</form>

@if (!string.IsNullOrWhiteSpace(q))
{
    <p>Found <strong>@results.TotalResults</strong> results for "@q"</p>

    @foreach (var item in results.Items)
    {
        <article>
            <h3><a href="@item.Content.Url()">@item.Content.Name</a></h3>
            <p>@item.Content.Value<string>("metaDescription")</p>
        </article>
    }

    @if (results.TotalPages > 1)
    {
        <nav>
            @for (var i = 1; i <= results.TotalPages; i++)
            {
                <a href="?q=@q&page=@i" class="@(i == page ? "active" : "")">@i</a>
            }
        </nav>
    }
}
```

## 11.7 Configuration

Search works **out of the box** with zero configuration. Optional settings:

| Item | Action |
|------|--------|
| Install SearchPlus | `dotnet add package uTPro.Feature.SearchPlus` → rebuild ExternalIndex |
| Custom fields | Pass `fields` param to `Search()` to target specific properties |
| Custom sort | Pass `orderBy` (e.g. `"updateDate Long desc"`) for date-sorted results |
| Scope restriction | Use `scopeNodeId` to limit results to a content subtree |
